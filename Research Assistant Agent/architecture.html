③ Orchestration Layer
🗺️
Planner Agent
src/planning_agent.py · planner_agent()
Calls Gemini to produce a structured research plan (up to 7 steps). Enforces mandatory first/second/final steps via contract rules.
LlmAgent gemini-2.0-flash JSON coercion
🔀
Executor Router
src/planning_agent.py · executor_agent_step()
Reads each step title and routes to the correct specialist agent based on keyword matching (research / writer / editor).
Keyword routing History injection
Step 1: Tavily web search → Step 2: arXiv lookup → Step 3: Synthesise & rank → Step 4: Draft outline → Step 5: Editorial review → Step 6: Final Markdown report
ADK InMemoryRunner · run_async() → final response event

src/agents.py · writer_agent()

Editor Agent
src/agents.py · editor_agent()

Revision pass No commentary
ADK Runtime (per agent call)
InMemoryRunner
Isolated per-call runner. Avoids cross-request session leaks in threaded FastAPI environment.
InMemorySessionService
Fresh session per call. Created inside _run_agent() to ensure clean state each time.
_get_or_create_event_loop()
Creates asyncio loop per thread when none exists — required for FastAPI thread pool workers.
Tool function calls via ADK tool dispatch
⑤ Research Tools
🌍
Tavily Search
src/research_tools.py · tavily_search_tool()
General web search via Tavily API. Returns title, content, URL for each result. Requires TAVILY_API_KEY.
REST API TavilyClient
📄
arXiv Search
src/research_tools.py · arxiv_search_tool()
Queries arXiv Atom API. Fetches matching PDFs, extracts up to 6 pages of text via PyMuPDF or pdfminer.
Atom XML PyMuPDF pdfminer
📖
Wikipedia Search
src/research_tools.py · wikipedia_search_tool()
Background context lookup. Returns page title, N-sentence summary, and canonical URL.
wikipedia-py Summary API
Shared HTTP infrastructure
Shared requests.Session with retry adapter (5 retries, backoff 0.6s, handles 429/5xx). Pool of 10 connections, 20 max size.
GOOGLE_API_KEY / Vertex AI credentials → Gemini API

// Data Flow Summary
User submits prompt → POST /generate_report
FastAPI creates DB task, launches background thread
Planner builds step list → Executor routes each step
ADK LlmAgent calls Gemini; Research agent uses tools
Tools hit Tavily, arXiv, Wikipedia APIs; return dicts
Final Markdown report saved to DB, streamed to UI
